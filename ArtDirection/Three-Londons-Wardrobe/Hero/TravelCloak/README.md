# Hero travel cloak

The default hero uses `/Game/Characters/Hero/TravelCloak/BP_HeroTravelVisual` through the `HeroVisual` child on `/Game/Characters/Hero/Sample/BP_HeroSampleCleanTest`. The replacement has fitted black trousers, a close black shirt, plain dark footwear, full wrist-length sleeves, and a single open-front drape. The previous `BP_HeroSampleVisual` is retained alongside it and can be restored by reassigning `HeroVisual`. The replacement visual uses the existing MetaHuman face mesh and groom.

`Wizard_Travel_Cloak_Reference.png` is the garment-only reference generated with built-in ImageGen. The prompt requested an ankle-length charcoal medieval travel cloak with an open front, an antique brass closure, slim wrist-length sleeves, a folded shawl collar, a subtle burgundy lining, and an invisible wearer in an A-pose on transparent background. `Wizard_Travel_Cloak_Projection.glb` is the local Hunyuan3D-2 untextured reconstruction. It contains 333,801 source vertices. The Blender fitting script samples the source mesh to retopologize the drape to a single continuous 2,745-vertex panel, resizes the panel for the actual character, and derives the fitted baselayers and arm sleeves from the target body surface and skin weights. The in-game drape uses separate plain exterior and lining colors.

Reopen `Hero_TravelCloak_Fit.blend` to inspect the fitted outfit, fit body, skeleton, and hidden reconstructed source. To rebuild, open `../SimpleHero/Hero_SimpleOutfit_Fit.blend` and run `fit_travel_cloak.py` in Blender. It writes the FBX exports and opacity mask to `Intermediate/TravelCloak`. `import_travel_cloak.py` imports the assets on the same Unreal body skeleton, uses the native body as pose leader, adds the new texture to the body-only skin mask, and configures Chaos Cloth against the native hero physics asset. The top of the drape is pinned and the allowed movement increases toward the hem. Sleeves remain driven by the skeletal pose.

The process follows the Blender native bone-weight fitting and Epic garment techniques described in the [Blender Data Transfer documentation](https://docs.blender.org/manual/en/latest/modeling/modifiers/modify/data_transfer.html), [Epic MetaHuman Customization guide](https://dev.epicgames.com/community/learning/tutorials/43dR/unlocking-the-potential-of-metahuman-customization-a-guide-for-unreal-engine-developers-artists), and [Unreal Chaos Cloth overview](https://dev.epicgames.com/documentation/unreal-engine/panel-cloth-editor-overview?lang=en-US).

Update, 14 November 2026: the `TravelDrape` component now uses `SK_HeroTravel_Drape_Coat`, built by `fit_heavy_coat.py` (smooth panel, spine-to-pelvis skin weights, heavier Chaos settings). The `_Mantle` drape below had a zig-zag rest mesh and is kept only for reference. See `ArtDirection/Clothing-Fit-Audit/HeroCoat-Cloth-Fix.md`.

The playable visual uses the `_GeneratedSurface` shirt, trousers and sleeve meshes, the `_Generated` boot pair, and the `_Mantle` drape. The boot pair comes from `Hero_BlackBoot_Reference.png` (built-in ImageGen) and `Hero_BlackBoot_Projection.glb` (local Hunyuan3D-2), with 246,377 source vertices. `fit_generated_boots.py` removes isolated fragments, fits the reconstructed shell to the native heel, ball, and ankle, and transfers normalized skin weights. The final pair has 7,880 vertices and retains the generated toe box, cuff, sole and leather folds. The continuous drape curves over the shoulders and uses the same reconstructed travel cloak source.

A test in the default crowd map confirmed the hero wore that visual with the original coat and tails cleared, the native face and groom bound, and the same locomotion animation graph. The cape ran one Chaos instance with 2,364 dynamic and 381 pinned vertices. Test movement reached 500 cm/s and a 109 cm jump offset. The close-up and moving screenshots in `Intermediate/TravelCloak/PIE_HeroTravel_Generated*.png` show the actual boots and over-shoulder cape. Some angular shoulder folds and a calf crossing the drape during the jump remain visible. The UV mask sampling retained 1,104 hand vertices and hid all sampled arm, torso, leg and foot vertices.

`Hero_TightShirt_Reference.png` and `Hero_TightTrousers_Reference.png` depict the simple black base garments. The matching Hunyuan3D-2 source GLBs have 438,576 and 141,584 vertices, respectively. In `Hero_TravelCloak_GeneratedFit.blend`, `fit_generated_layers.py` transfers their reconstructed folds and local depth onto the fitted MetaHuman garment topology. The sleeve folds are transferred from the cloak reconstruction. This preserves the body-fit silhouette and native skin weights and avoids importing dense reconstruction meshes. The final five pieces have 12,545 vertices total with one UV set and normalized weights each. The two fitted base garments preserve the original close silhouette and use matte black materials. These are retopologized surface transfers of each image-to-3D source, with the native body used to set the low-frequency dimensions.
