# NPC behaviour plan

Status: working draft, 2026-11-21. The game is changing completely, so NPCs are being designed from scratch. The old NPC system, the conversation code and every recorded voice line were removed on 2026-11-21; git history still has them. Only the 137 custom designed voices carry over, defined in `ArtDirection/Audio/data/voice_roster.json`.

The plan is being worked out in a shared doc: [Reflections — NPC Behaviour Plan](https://claude.ai/artifact/7uQmF7zhGqpDiEU8nhB8Ya). Once it's approved, the full plan will be copied into this file.
