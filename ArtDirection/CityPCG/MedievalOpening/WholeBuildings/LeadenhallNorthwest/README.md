# Northwest Leadenhall whole-building models

Four closed medieval source buildings follow the reviewed northwest
Leadenhall plots: one trading range, one market building and two workshops.
The two adjoining workshops each preserve all four shared wall edges. The
matching plan is included with the source and Unreal-ready FBXs.

The manifest records each file hash, footprint, pivot, materials and geometry
audit. The four Blender round trips passed closed-solid, winding, UV,
material and footprint-edge checks. These are **offline source models**;
they have not been imported, placed or tested in the playable city.

Unreal appearance and collision, nearby authored actors, street and quest
routes, rooftop traversal and runtime streaming still need review. See
`Tools/CityPCG/WHOLE_BUILDING_GENERATOR.md` and
`../../NEXT_WHOLE_BUILDING_BLOCKS.md` for generation and survey details.
