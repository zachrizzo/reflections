# East Royal Mint whole-building models

These four closed medieval source buildings follow the offline candidate
plots east of Royal Mint Court. The attached plan and manifest record their
surveyed footprints, pivots, roof profiles, materials and source/prepared
FBX hashes. Blender round trips passed the closed-solid, winding, UV,
material and footprint-edge checks.
The `*_preview.png` images are Blender renders of the same audited geometry.

These are **review-only source models**. Some neighboring tile and overlay
exports are missing, and the blocks have not been imported, placed or tested
in the playable city. Complete the missing neighbor, authored-actor, quest,
street, rooftop and Unreal collision checks described in
`../../EAST_TOWER_WHOLE_BUILDINGS.md` before approving a replacement.

`Source` contains the authored FBXs; `UnrealSource` contains the
triangulated, Y-reflected copies prepared for the UE legacy FBX importer.
