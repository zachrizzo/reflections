# Reviewed medieval prop source candidates

These five raw TripoSR GLBs were visually reviewed as candidate source art for medium-distance props. They are not placed in Gray London or approved for gameplay. The accepted set is AppleBasket, BakersTray, MerchantCrate, PottersStock and MarketWell; MarketHandcart is excluded pending repair.

They were produced by [hosted run 43744477013](https://github.com/zachrizzo/reflections/actions/runs/43744477013) using the pinned MIT-licensed TripoSR source and model. Each adjacent provenance JSON records its source image, model, generation settings and exact GLB SHA-256. The GLBs are stored in Git LFS and were independently read back from fresh stores before publication.

Each mesh has POSITION and normalized RGBA COLOR_0, with no authored UVs, normals or material. Units, pivot and forward orientation are not established; unseen surfaces were inferred from a single image. Check each mesh, choose a physical scale and pivot, create a vertex-color material, and verify Unreal rendering, normals, collision, navigation, placement and performance before gameplay use. The first generated diagnostic images sampled faces and are not reliable for topology review; full-face review sheets were used for the candidate decision.
