# itch.io screenshots and cover

Take these on Sunday morning from the **recording copy** of the rehearsal build, in the same session as the video ([video-plan.md](video-plan.md)). Every existing capture is from test maps or the GASP sample, and some carry the old "RED LONDON" banners, so **none of them go on the page**.

**How:**
- Console `HighResShot 1920x1080`, which writes to `C:\ReflectionsRec\reflections\Saved\Screenshots\Windows\`.
- Or **Win+Alt+PrtScn** (Game Bar), which writes to `Videos\Captures`.
- Run `DisableAllScreenMessages` first, and make sure the console is closed.
- Keep the HUD in shots 1, 4 and 6, so judges see it's gameplay. In the others, frame so the HUD doesn't cover the subject.
